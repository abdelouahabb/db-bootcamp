## Overview: The 15-Volume Meteorological Systems Engineering Library

Welcome to the **Master Reference Cards Library** for the **5-Day Weather Forecast Database Engineering Bootcamp**. Together with the three dedicated root-level guides (**[SQL_BASICS_CRUD_GUIDE.md](../SQL_BASICS_CRUD_GUIDE.md)**, **[MONGODB_NOSQL_BASICS_CRUD_GUIDE.md](../MONGODB_NOSQL_BASICS_CRUD_GUIDE.md)**, and **[POSTGIS_VS_MONGODB_GEOSPATIAL_AND_PARTITIONING_CHEATSHEET.md](../POSTGIS_VS_MONGODB_GEOSPATIAL_AND_PARTITIONING_CHEATSHEET.md)**), these 15 self-contained technical reference volumes (**8,275+ lines** of deep storage internals, ASCII byte/page diagrams, mathematical proofs, production runbooks, and forensic benchmarks) serve two complementary purposes:

1. **Foundational CRUD Warm-Up & Deep-Dive Architectural Companion (During the Bootcamp):** Attendees start with **[SQL_BASICS_CRUD_GUIDE.md](../SQL_BASICS_CRUD_GUIDE.md)** (`672 lines`), **[MONGODB_NOSQL_BASICS_CRUD_GUIDE.md](../MONGODB_NOSQL_BASICS_CRUD_GUIDE.md)** (`523 lines`), and **[POSTGIS_VS_MONGODB_GEOSPATIAL_AND_PARTITIONING_CHEATSHEET.md](../POSTGIS_VS_MONGODB_GEOSPATIAL_AND_PARTITIONING_CHEATSHEET.md)** (`425 lines`) to master `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `GROUP BY`, `JOIN`, MongoDB `find` / `insertOne` / `updateOne` / `deleteOne` / `aggregate`, and `PostGIS` vs. `2dsphere` / `PARTITION BY RANGE` vs. Time-Series bucketing across every bootcamp database (`weather_ops.db`, `weather_telemetry.db`, `weather_ops`, `weather_nosql`, and `weather_telemetry_db`), and then dive into Reference Cards `00`–`14` for byte-level internals and reproducible benchmarks.
2. **24/7 Operations Center On-Call Runbook (In Production):** When a national meteorological service encounters a production database incident—such as a `database is locked` exception, an `AccessExclusiveLock` outage, a MySQL Next-Key Lock stall, a Ceph `NEARFULL` alert, or a silent synoptic station dropout—engineers can use the **Symptom-to-Reference-Card Diagnostic Lookup Table** below to jump straight to the exact forensic query and remediation procedure.
